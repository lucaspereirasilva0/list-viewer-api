# Firebase Auth Setup Guide

This document describes, step by step, how to configure **Firebase Authentication** for the List Manager, including integrations in the frontend (React) and backend (Go) and Heroku deployment considerations.

---
## 1. Overview

| Aspect | Details |
|---------|----------|
| **Service** | Firebase Authentication (managed by Google) |
| **SDK** | Free libraries (`firebase` for Web/Node, `firebase.google.com/go/v4` for Go) |
| **Spark Plan (Free Tier)** | ≤ 10,000 users and ~50,000 logins/month |
| **Model** | Stateless (JWT/OIDC) – backend only validates signature |
| **Benefits** | 1-click Google login, email/password, future MFA, no own password infrastructure |

---

## 2. Creating the Firebase Project

1. Go to <https://console.firebase.google.com> and sign in to your Google account.
2. Click on **Add project** and enter a name (e.g., `list-manager`).
3. Follow the wizard until the creation is complete (you can disable Google Analytics if you don't want it).

---

## 3. Enabling Firebase Authentication

1. In the project dashboard, open **Authentication** and click on **Get started**.
2. **Sign-in method** tab:
   1. Click on **Email/Password**, enable it and save.
   2. Click on **Google**, enable it and save.

---

## 4. Registering the Web Application

1. In **Project settings** (⚙ icon, top left corner) → **General** tab.
2. **Your apps** section → click the `</>` icon to add a Web app.
3. Enter a nickname (e.g., `frontend`) and check *Config Firebase Hosting* **only** if using Hosting (optional).
4. Copy the generated keys (`apiKey`, `authDomain`, `projectId`, etc.). They will be used in the frontend.

---

## 5. Authorized Domains

Firebase requires you to list allowed domains to execute the login flow:

1. **Authentication** → **Settings** (gear icon inside Authentication).
2. **Authorized domains** section → **Add domain**:
   * `localhost` – local development.
   * `meuapp.herokuapp.com` – URL after deployment.

---

## 6. Service Account

The backend needs to verify the ID-Token generated by Firebase.

1. **Project settings** → **Service accounts**.
2. Click on **Generate new private key** and download the JSON.
3. In Heroku, define the environment variable `GOOGLE_APPLICATION_CREDENTIALS` pointing to the path of this file in the container, or store the JSON content in `FIREBASE_CREDENTIALS` and load via code.

## 7. Frontend Integration (React/PWA)

```bash
npm i firebase@^9
```

```ts
// src/lib/firebase.ts
import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth";

const firebaseConfig = {
  apiKey: import.meta.env.VITE_FB_API_KEY,
  authDomain: import.meta.env.VITE_FB_AUTH_DOMAIN,
  projectId: import.meta.env.VITE_FB_PROJECT_ID,
};

export const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);
```

Google login example:

```ts
import { GoogleAuthProvider, signInWithPopup } from "firebase/auth";
import { auth } from "./lib/firebase";

export async function loginWithGoogle() {
  const provider = new GoogleAuthProvider();
  const result = await signInWithPopup(auth, provider);
  return result.user;
}
```

Get ID-Token and send to backend:

```ts
const idToken = await auth.currentUser?.getIdToken();
await fetch("/api/session", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ idToken }),
});
```

## 8. Backend Integration (Go)

### Dependency
```bash
go get firebase.google.com/go/v4
```

### Firebase Client Initialization
```go
package main

import (
    "context"
    "log"
    "os"

    firebase "firebase.google.com/go/v4"
    "google.golang.org/api/option"
)

func newFirebaseAuth(ctx context.Context) *auth.Client {
    cred := option.WithCredentialsFile(os.Getenv("GOOGLE_APPLICATION_CREDENTIALS"))
    app, err := firebase.NewApp(ctx, &firebase.Config{ProjectID: os.Getenv("FIREBASE_PROJECT_ID")}, cred)
    if err != nil {
        log.Fatalf("firebase init: %v", err)
    }
    client, err := app.Auth(ctx)
    if err != nil {
        log.Fatalf("firebase auth client: %v", err)
    }
    return client
}
```

### Verification Middleware
```go
func AuthMiddleware(client *auth.Client, next http.Handler) http.Handler {
  return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
    tokenStr := extractToken(r) // Header Authorization or cookie
    token, err := client.VerifyIDToken(r.Context(), tokenStr)
    if err != nil {
        http.Error(w, "unauthorized", http.StatusUnauthorized)
        return
    }
    ctx := context.WithValue(r.Context(), "uid", token.UID)
    next.ServeHTTP(w, r.WithContext(ctx))
  })
}
```

## 10. Security and Best Practices

* Use `HttpOnly Secure SameSite=Strict` cookies if you opt to send the ID-Token to the backend via cookie.
* Keep `access token` short (1 h) and let the SDK renew automatically.
* Enable verified email protection and login attempt limits.
* Evaluate enabling MFA in the future.

## 12. Local Development

### Option A – Use Real Firebase Project

1. Add `localhost` and `127.0.0.1` in **Authentication → Settings → Authorized domains**.
2. Create a `.env` file in the `frontend/` directory with:
   ```
   VITE_FB_API_KEY=...
   VITE_FB_AUTH_DOMAIN=...
   VITE_FB_PROJECT_ID=...
   ```
3. Download the JSON from **Service Account** and export variables in the development terminal:
   ```bash
   export FIREBASE_PROJECT_ID=<your-project-id>
   export GOOGLE_APPLICATION_CREDENTIALS=$(pwd)/credentials/firebase.json
   ```
4. Run local services:
   ```bash
   # Frontend
   cd frontend && npm run dev
   # Backend
   go run ./cmd/server
   ```
5. Login via Google or email/password normally (requires Internet connection).

### Option B – Use Firebase Emulator Suite

1. Install the Firebase CLI if you don't have it yet:
   ```bash
   npm install -g firebase-tools
   ```
2. Initialize the Authentication emulator (in the project root):
   ```bash
   firebase init emulators   # mark only "Authentication"
   ```
3. Start the emulator:
   ```bash
   firebase emulators:start --only auth
   ```
4. Adjust the frontend to connect to the emulator (example in `src/lib/firebase.ts`):
   ```ts
   import { connectAuthEmulator } from "firebase/auth";
   if (import.meta.env.DEV) {
     connectAuthEmulator(auth, "http://127.0.0.1:9099");
   }
   ```
5. In the Go backend, inform the SDK that it should use the emulator:
   ```bash
   export FIREBASE_AUTH_EMULATOR_HOST=127.0.0.1:9099
   ```
6. Access the emulator web interface at <http://127.0.0.1:4000> to create test users.

> Tokens generated by the emulator are only valid in the local environment and do not work against Firebase in production.
